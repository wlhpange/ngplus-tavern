# 星穹秘契 · Astral Covenant

> 二周目协会（NG+ Guild）品牌设计系统 · v1.0
> 移动优先（390px 基准）· 暗色 · 游戏质感

---

## 0. 方向命名与由来

**星穹秘契（Astral Covenant）** 是把第一轮的两个方向真正缝合后的正式方向：

| 来源 | 贡献 |
|---|---|
| **A 星穹罗盘** | 骨架与数据语言：4pt 精确网格、发丝线分层、星座雷达、辉光节点、克制的留白、高对比宋体标题 |
| **C 秘契书库** | 仪式与材质心理：紫墨底、古金箔、蜡封作为完成/评级的核心材质、晋升时的全屏高光 |

一句话定义：

> **一架刻在紫墨羊皮纸上的观星仪——数据是星，承诺是封。**

- 平常的页面安静、精确、冷：靠发丝线和辉光点表达空间，不靠大投影。
- 仪式只发生在两个时刻：**完成委托**与**评级晋升**。此时蜡封烙下、金箔扫光、金币雨洒落。
- 会长之谜的视觉落点：他执笔了你的秘契，并且似乎早已读完了这张星图。

**为什么是这个混搭而不是任一单选：**
- 纯 A 太冷、太像工具，承载不了「盖章、金币雨」的奖励快感；
- 纯 C 太华丽，长时间使用会累，且数据可视化会失去精确感。
- 混搭后，A 负责「每天都看得下去」，C 负责「值得截图发出去」。两者用「青=交互 / 金=价值」的**双通道颜色规则**隔开，不打架。

## 1. 设计原则

1. **数据要有星象感，但不失真。** 所有读数走等宽数字并右对齐；一切间距落在 4pt 网格上。雷达图的形状必须真实反映数值，不能手绘目测。
2. **仪式是稀缺资源。** 蜡封、金箔、金币雨只属于「完成」与「晋升」。日常界面保持安静，仪式才有冲击力。
3. **双通道强调，各司其职。** 星辉青 = 交互与数据（当前 tab、焦点、进度、雷达）；古金 = 价值与仪式（XP、金币、难度、评级、盖章）。二者不在同一语义里竞争。
4. **用发丝线分层，不用重阴影。** 暗色空间由 1px 描边、极低透明度分层和局部辉光构成。
5. **契约的质感。** 卡片有极淡的金箔内描边（`--inset-gold`），像压印在皮革上的契约边；完成时这层金线会「点亮」。
6. **移动优先。** 所有触控目标 ≥ 44px；正文栏宽天然受 390px 约束，不出现横向滚动。

## 2. 色彩策略总览

- 底色（紫墨）与价值色（古金）**来自 C**；文字（冷星白）与交互色（星辉青）**来自 A**。
- 六维属性使用一套独立的、低饱和的**分类色**（§3.7），只在数据可视化中出现，不参与界面强调。
- 完整色板以 CSS 变量形式见 `tokens.css`，变量注释标注了本节章节号。

### 3.8 增补语义 · 成功 / 禁用（第二轮增补 [融]）

| Token | 色值 | 名称 | 用途 |
|---|---|---|---|
| `--success` | `#6FBF9A` | 苔玉绿 | 连接通过、已开启、校验成功（填充 / 图标 / 描边） |

> 成功态是双通道之外的**第三种系统反馈**：它不参与价值（金）与交互（青）的竞争，只在「系统确认了一件事」时出现，且每屏最多一次。青回答「你现在能操作什么」，绿回答「刚才那件事成了」。

禁用态不另造色，由既有中性色推导：

| Token | 值 | 用途 |
|---|---|---|
| `--disabled-fg` | `= --faint` | 禁用态文字（唯一允许低于 4.5:1，见 §8） |
| `--disabled-bg` | `surface-2` 55% | 禁用态底 |
| `--disabled-border` | `= --border` | 禁用态描边 |

> 禁用按钮保持形状与尺寸不变，只降对比、去辉光、去位移反馈；不改变文案长度，避免布局跳动。

## 4. 字体 · Typography

### 4.1 字体栈

| 角色 | 字体栈 | 说明 |
|---|---|---|
| 显示 Display | `"Source Han Serif SC","Noto Serif SC","Songti SC","STSong","SimSun",Georgia,serif` | 高对比宋体，像星图上的蚀刻铭文；一切标题与任务名 |
| 正文 Body | `"PingFang SC","Hiragino Sans GB","Microsoft YaHei",system-ui,sans-serif` | 人文无衬线，长文耐久读 |
| 数字 Mono | `"JetBrains Mono",ui-monospace,"SF Mono",Menlo,Consolas,monospace` | 所有数值、时间、徽章标签；启用 `tabular-nums` |

> 不加载网络字体，系统优先；宋体缺失时回退到 Georgia 仍保留衬线气质。

### 4.2 字号阶梯（移动端）

| Token | 值 | 用途 |
|---|---|---|
| `--fs-display` | 30px | 页面大标题（角色名 / 评级） |
| `--fs-h1` | 24px | 区块主标题 |
| `--fs-h2` | 19px | 卡组标题、任务卡标题 |
| `--fs-h3` | 16px | 卡片标题基 |
| `--fs-body` | 14px | 正文 |
| `--fs-sm` | 13px | 按钮、小正文 |
| `--fs-meta` | 12px | 次要信息、报酬 |
| `--fs-micro` | 10.5px | 徽章、角标、导航标签 |

行高：标题 `--lh-tight` 1.18；正文 `--lh-body` 1.55。等宽小字字距 `--ls-wide` 0.08em。

### 4.3 排版规则

- 标题一律 `var(--font-display)`；正文、按钮用 `var(--font-body)`；数字用 `var(--font-mono)` + `font-variant-numeric: tabular-nums`。
- 任务卡标题 = 宋体 17–19px，像契约条目名，给游戏感。
- 徽章/标签用等宽 + 大写，`letter-spacing` 拉开，像铭牌。

## 5. 圆角 / 阴影 / 间距

### 5.1 圆角

`--radius-xs 6` · `--radius-sm 10` · `--radius 14` · `--radius-lg 18` · `--radius-xl 24` · `--radius-pill 999`。
卡片用 `--radius-lg`，按钮/输入用 `--radius-sm`，chips 与徽章用 `pill`。整体收敛，避免圆润可爱。

### 5.2 间距（4pt 网格）

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 72`，左右安全边距 `--gutter 16px`。
卡片内边距 13–14px，卡片间距 10–12px，区块间距 24–32px。

### 5.3 阴影与辉光

| Token | 用途 |
|---|---|
| `--shadow-1` | 卡片静置的极轻投影 |
| `--shadow-2` | 浮层/设备外框 |
| `--inset-gold` | 卡片内金线（金箔压印隐喻）；完成时点亮 |
| `--glow-accent` | 星点/进度条的青色辉光 |
| `--glow-gold` | 金色徽章、仪式的辉光 |

> 暗色下优先用描边和辉光分层；投影只用于浮起层级，不用于装饰。

## 6. 动效 · Motion

### 6.1 基础节奏

| Token | 值 | 用途 |
|---|---|---|
| `--dur-1` | 120ms | 按压、描边变化 |
| `--dur-2` | 200ms | hover、切页 |
| `--dur-3` | 320ms | 面板/浮层入场 |
| `--ease-out` | cubic-bezier(.22,.61,.36,1) | 默认 |
| `--ease-spring` | cubic-bezier(.34,1.56,.64,1) | 星点着落、徽章回弹 |

hover 一律通过**抬起背景明度**（`surface → surface-2`）或加辉光实现，**绝不把文字调暗**。所有可聚焦元素必须有青色 `:focus-visible` 焦点环。

### 6.2 星点着落（日常反馈）

完成一个属性读数的提升时，对应星点用 `--ease-spring` 放大 1.0→1.25→1.0，并伴随 `--glow-accent` 的短促闪烁。时长 320ms。

### 6.3 仪式动效规格（核心）

三幕叠加，总时长约 2.4s：

**第一幕 · 蜡封烙下**（`--ritual-seal` 620ms，`--ritual-ease`）
1. 背景 scrim 淡入至 `bg 78%` + 3px 模糊。
2. 蜡封从 `scale(2.2) rotate(-16deg) opacity(0)` 起手；
3. 到 55% 时砸到 `scale(.94)`，产生一次 6px 的径向冲击环扩散；
4. 回弹到 `scale(1.04)`，定为 `scale(1) rotate(-8deg)`。

**第二幕 · 金箔扫光**（`--ritual-foil` 900ms，延迟 180ms）
一道 45° 金白高光带（宽 60px，`--gold` 到透明）从左下横扫到右上，掠过蜡封与标题；同时卡片内金线 `--inset-gold` 由 12% 亮到 90% 再回落到常态。

**第三幕 · 金币雨**（`--ritual-coin` 1600ms，延迟 500ms）
24–32 枚金币从顶部随机 x 位置、随机延迟落下，旋转 ±180°，落到底部后淡出。金币用 `--gold` 圆片 + 内圈高光，不作拟真贴图。

**收尾**：仪式浮层 200ms 淡出；评级字母以星等逐级增亮的方式切换（F→E→D…只升不降）。所有仪式动效在 `prefers-reduced-motion: reduce` 下降级为一次 200ms 的静态盖章闪现。

### 6.4 门开动效 · The Gate（`prototypes/gate.html` 专用，第二轮增补）

冷启动第一幕。它是「安静的门厅」，不是「金币雨」：**不启用蜡封、不启用金箔扫光、不启用金币雨**，只用门缝的一线金光完成仪式。

**场景**：紫墨门厅；门板为紫墨面 + 极淡金箔内线；门缝透出金光；门楣一盏长明灯。

| 状态 | 规格 |
|---|---|
| 静置 | 门板 `rotateY(0)`；门后金光层 `opacity .12`；门楣灯 `--glow-gold` 以 3.2s 呼吸 |
| hover | 门板 `rotateY(-9deg)` 抬起 2px，金光到 `opacity .45`（`--dur-2` `--ease-out`） |
| active | 门板 `rotateY(-4deg)` 下移 1px（`--dur-1`） |
| 推开（点击） | `--dur-door` **700ms** `--ease-out`：门板绕左轴开到 `rotateY(-108deg)`，金光到 `opacity .95`，门厅轻微前推 `scale(1.02)` |
| 收束 | 门板定格后 200ms，门厅整体 `opacity → 0`（`--dur-3`）；提示由「推开它」换成「门开了……」 |

`prefers-reduced-motion: reduce`：跳过 3D 旋转，门板直接 `opacity → 0`，金光闪现一次 200ms，文案立即切换。

### 6.5 交接瞬间 · The Handover（`prototypes/masters.html` 会长更替）

更换会长确认后，全局进入「交接仪式进行中……」禁用态。这是 `--dur-handover` **1200ms** 的一次盖章，**不是**一次庆祝——浓度规则：只允许一枚徽记 + 一道冲击环。

1. **遮蔽**（0–300ms）：scrim 淡入至 `bg 72%` + 2px 模糊；内容 `opacity .35` 且指针停用。
2. **落印**（300–1000ms）：中央一枚金色圆形徽记（新会长名字首字）自 `scale(.6) opacity 0` 以 `--ease-spring` 落定 `scale(1)`；外圈一道金色冲击环扩散一次（比 §6.3 更小）。
3. **收束**（1000–1200ms）：浮层 `opacity → 0`；随后「老会长留下了一封信」信卡以 `--dur-3` 上浮入场。

`prefers-reduced-motion: reduce`：降级为 200ms 静态闪现，无冲击环。

## 7. 组件规范 · Components

### 7.1 应用栏 App Bar（`--appbar-h` 64px）

协会徽记（金描边圆形，内嵌罗盘/星座 SVG）+ 页面标题（宋体 `--fs-h1`）+ 副题（等宽 `--fs-micro`，`--muted`）；右侧可放金币余额 chip（金）。

### 7.2 底部导航 Tab Bar（`--tabbar-h` 62px）

5 格：任务板 / 角色 / **会长对话（中央，金色圆形浮起按钮）** / 商店 / 设置。
- 未选中：`--muted`，线框图标；选中：`--accent` 图标 + 文字。
- 中央「会长对话」是唯一金色实心圆钮（46px，`--glow-gold`），因为对话是所有玩法的入口。
- 背景 `bg 88%` + `backdrop-filter: blur(14px)`，1px 顶部分割线。
- 每个入口触控高度 ≥ 44px。

### 7.3 任务卡 Quest Card

结构自上而下：
1. **类型徽章**（pill，等宽 `--fs-micro`，线框）：每日=青、一次性=冷星白、每周=秘法紫、主线里程碑=金（金淡底）。
2. **难度**：0.5–3.0，三颗星位；满星实心金、半星渐变、空星线框。等宽数字标注如 `1.5`。
3. **任务标题**：宋体 17–19px，`--lh-tight`。
4. **属性行**：主属性 chip（彩色图标+名）+ 副属性 chip（`--muted`）。
5. **进度**（仅进行中）：6px 圆角轨道 + 青色渐变填充 + `--glow-accent`；上下两行等宽小字「已进行 / 目标」。
6. **页脚**：连击火苗 ×N（`--flame`）· 报酬 `+XP` / `+金币`（金）· 截止时间（右对齐，逾期用 `--danger-text`）。
7. **操作**（上下文）：提议中=「接受委托」（青描边）；进行中=「汇报完成」（金描边）；逾期=「重新委托」（青描边）。**一律线框，不实心**，避免与中央对话钮争夺主行动。
8. **已完成**：右上角一枚蜡封徽记（`--danger` 蜡体 + `--gold` 内线 + 「契」字），且卡片内金线点亮。

材质：`--surface` 底 + `--border` 外框 + 内缩 6px 的极淡金线（`gold 10%`）。hover 抬到 `--surface-2` 并加亮边框，文字不变暗。

### 7.4 属性条 Attribute Bar

一行：属性图标（分类色）+ 名称 + 等级（等宽）+ 进度条 + 数值。
进度条 6px，填充用该属性的**分类色**渐变，末梢带同色辉光；轨道 `fg 8%`。属性条的填充色不是强调色，而是数据编码。

### 7.5 星座雷达 Constellation Radar

- 六边形：4 圈同心星轨网格（25/50/75/100%），轴线用 `--border`，网格线用 `border 60%`。
- 数据面：半透明青色填充（`accent 18%`）+ `accent-line` 描边，顶点为发亮星点（`--glow-accent`）。
- 轴标签用等宽小字置于顶点外侧。
- 圆心只允许放**一个**短 KPI（如 `Lv.12`）；其余数值一律移到外部的属性条或图例，避免同心层里堆叠文字。
- 雷达必须按真实数值绘制，禁止目测。

### 7.6 徽章 / 蜡封 Badge & Wax Seal

- **评级徽章**：圆形蜡封，直径 84–132px；蜡体为 `--danger` 径向渐变（左上高光），内圈 `--gold` 描边，中央宋体大字母（F→S）。
- **完成蜡封**：32–44px 小蜡封，压在卡片右上，`rotate(-8deg)`。
- **称号章**：小圆形金/灰，已获得用金，未获得用 `--faint` 线框并加锁。

### 7.7 按钮 Button

| 变体 | 样式 | 用途 |
|---|---|---|
| Primary | 金色实心，深字 `--on-gold` | 全页唯一主行动（如「举行晋升仪式」） |
| Secondary | `--fg` 线框，透明底 | 次级操作 |
| Accent-outline | 青描边 + 青字 | 卡片内「接受/重新委托」 |
| Gold-outline | 金描边 + 金字 | 卡片内「汇报完成」 |
| Ghost | 无框，`--muted` 字 | 弱操作 |

按钮最小高度 44px；hover 抬背景、加亮边框；`:focus-visible` 2px 青色焦点环 + 2px offset；`:active` 下移 1px。

### 7.8 称号墙 Title Wall

2 列网格。已获得：金描边圆形章 + 称号 + 获得日期；未获得：`--faint` 线框 + 锁 + 解锁条件。标题用宋体。

### 7.9 商品卡 Product Card（`prototypes/shop.html`，第二轮增补）

结构：**图标/色片 · 名称/描述/持有数 · 右侧价格+动作**。

- 卡底 `--surface` + `--border` 外框 + 内缩金线（同 7.3 任务卡的契约质感）。
- 图标位 44×44 圆角方；道具 / 礼物用单色描边图标（`--muted`，线框 `--border`）；皮肤用主题色片：`--flame/--gold`（炉火）、`--attr-mind/--accent-2`（夜航）、`--accent/--accent-2`（林间）、`--gold`（鎏金庆典）的 `color-mix` 渐变。
- 名称宋体 `--fs-h3`；**价格 = 金色等宽**（`--gold` + 金币图标）；描述 `--muted` `--fs-sm`；持有数等宽 `--fs-micro`（道具/礼物 `持有 ×N`，皮肤 `已拥有 / 未拥有`）。
- 动作列右对齐、上价格下按钮。道具/礼物「买下」= Accent-outline；皮肤「换上」= Accent-outline、「已装备」= Gold-outline 且不可点。
- **买不起**：按钮禁用为「金币不够」，走 `--disabled-fg/bg/border`，**价格保持金色不降对比**。
- 分组标题：宋体 `--fs-h2` + 一行 `--muted` 提示；**空组整组隐藏**。
- 页脚「换回原来的样子」：任何皮肤处于已装备时显示，Ghost 样式。

### 7.10 人物卡 Persona Card（`prototypes/masters.html`，第二轮增补）

- 头像圆章 44px：`--surface-3` 底 + 宋体名字首字；现任者用金淡底 + `--gold-line` 描边。
- 风格标签：等宽 pill，`--border` 线框 + `--fg`（中性，不用青/金，避免与双通道语义竞争）。
- 卡身 `--surface` + `--border`；**现任卡**：`--gold-line` 外框 + `--inset-gold` 点亮 + 右上「现任」金章。
- 自我介绍一行（`--fg`），背景故事 `--muted` `--fs-sm`。
- 动作：「选 ta / 换成 ta」Accent-outline；现任卡动作降为禁用「当前会长」。
- **第五扇门占位**：`--border-strong` 虚线边框 + 信封图标 + 「都不对味？」 + `--faint` 「信纸还没印好…」，整卡禁用。
- 底部兜底：「先不选，直接进门」Ghost 文本钮。
- 交接进行中：全局 `--disabled` 浮层（见 7.13 与 §6.5）。

### 7.11 表单控件 · 信笺行 Letter Field（`prototypes/settings.html`，第二轮增补）

> 产品红线：**不能有填表单感**。全应用唯一表单页，做成「给会长的信笺 / 档案登记」。

- 每行 = 上行等宽 `--fs-micro` 标签（`--muted`）+ 可选说明；下行 input **无边框、透明底**、`--fg`，仅一条 `--border` 底线。
- 聚焦（`:focus-within`）：底线转 `--accent` + 一行 `--glow-accent`；占位符 `--faint`。
- 密码型：placeholder 即掩码 `sk-••••••••7f3a`；留空保存 = 保持现有 Key。
- 信笺卡：`--surface` + 金箔内线 + 顶部宋体小标题；右下角一枚小蜡封「契」作落款。
- 动作：保存 = Primary 金实心（**全页唯一金色实心按钮**）；测试连接 = Secondary；清除已存 Key = 危险描边（`--danger-text` 描边，仅 `db` 来源时出现）。

### 7.12 状态卡 State Card（settings / notify，第二轮增补）

- 结构：左侧状态点（10px 圆：成功 = `--success` + 辉光、未配置 = `--faint`、被拦 = `--danger`）+ 状态标题 + 右侧等宽状态码；下方 1–2 行说明。
- 掩码行：等宽 `--fg`。
- 来源三态 chip：面板设置 = `--accent` 描边、环境变量 = `--arcane-text` 描边、未配置 = `--faint` 线框。
- 测试结果双态：成功「通了。模型 X 应答正常，耗时 N ms。」用 `--success-text`；失败「没通：{error}」用 `--danger-text`。成功态每屏只出现一次。

### 7.13 选择器 Selector & Segmented（notify / masters，第二轮增补）

- **时间选择**：原生 `<select>`，`--surface-2` 底 + `--border` + `--radius-sm`，聚焦青环；当前时间以等宽大字 `--fs-display` 呈现（`--fg`，不用金——时间是约定，不是价值）。
- **状态演示 segmented**：等宽微型（`--fs-micro`），未选 `--muted` + `--border`，选中 `--accent` + `--accent-soft`；仅用于原型演示多状态机。
- **全局禁用浮层**（交接）：`--bg 72%` + blur，中央金徽记 + 「交接仪式进行中……」等宽金字，`aria-busy` 标注。

## 8. 无障碍与对比度

- 所有正文/次要文字对底色 ≥ 4.5:1（`--fg` ≈15.8:1，`--muted` ≈5.4:1，`--gold` ≈8.4:1，`--accent` ≈10:1）。
- `--danger`（蜡封红）只作填充，红字用 `--danger-text`。
- hover/focus/active 只提升对比，绝不降低。
- 触控目标 ≥ 44×44px。
- 尊重 `prefers-reduced-motion`。
- 390px 视口零横向滚动。
