# 手动验收清单（Android）

APK：`/Users/wlhpange/Downloads/ngplus-tavern-0.1.1.apk`  
包名：`com.wlhpange.ngplus`（debug 签名，可直接侧载；不要上架）

> 建议在一台真机上测；模拟器（尤其 SwiftShader）的帧率和文件选择器不能代表真机。

## 0. 第一次配置
- [ ] 设置 → 模型与渠道 → 自定义 API：填 OpenAI 兼容地址（到 `/v1` 为止）、模型名、Key；点「测试连接」，应返回「通了」。
- [ ] （可选）DeepSeek / OpenCode Go：填真实 Key 再测；没有 Key 会提示未配置。
- [ ] 设置 → 生图：打开开关，填一个 OpenAI 兼容 `images/generations` 接口和模型；点「测试生图」，应出图。

## 0.5 R18 开关
- [ ] 设置页「协会章程」里直接可见「R18 内容」开关（无需连点，无暗门）。
- [ ] 打开后再进聊天/酒馆，提示词会注入 `R18_GUIDELINES` / `R18_POST_RULES`；关掉即恢复。
- [ ] 开关状态杀进程重开后保持；这是本机设置，Web 端不会同步。
- [ ] 验证方法：把「模型与渠道」指向仓库的 `tools/stub-server.mjs`，发一条聊天消息，终端应打印
      `[stub] chat prompt ... r18=true postRules=true`；关掉 R18 后再发一条，应变成 `r18=false postRules=false`。

## 0.6 音效
- [ ] 设置页「音效」打开后：商店购买/送礼、技能点亮、结算卡、升级/晋段、提交异议应各有一声短音。
- [ ] 关掉「音效」后同样操作应全部无声；杀进程重开仍保持关闭。
- [ ] 手机处于静音模式或媒体音量为 0 时不响，是系统行为，不是 App 问题。
- [ ] 音效应与震动同时存在、互不影响；连续操作不应出现叠音或爆音。

## 1. 推门 / 会长
- [ ] 清数据后首次启动：推门 → 选会长（薇拉/加洛/莱恩/墨）→ 进入任务对话。
- [ ] 「更换会长」：切换会长，当前会长标记和开场白跟着变。
- [ ] 「新增会长」：只填名字/描述，点「AI 生成」，其余字段应被补全；点「创建这位会长」后出现在列表。
- [ ] 会长卡：设置头像、生成形象、修改形象都能打开对应弹层。

## 2. 对话
- [ ] 任务模式发一句话：回复应流式出现，历史落库。
- [ ] 切到聊天模式：显示开场白；「换一条开场白」可用；新建/改名/删除会话；上传会话背景后背景生效。
- [ ] 长按/点「删除」删一条消息：消息消失；有配图时配图一起删。
- [ ] 杀进程重开：消息、会话、背景仍在。
- [ ] 发一条带 **粗体**、*斜体*、`code` 的消息（或让会长回），聊天气泡应渲染格式而不是显示星号。

## 3. 委托
- [ ] 让会长建一份委托 → 告示板出现「待接受」→ 接受后变「进行中」。
- [ ] 汇报完成 → 出现结算卡（XP/金币/属性），面板数值同步。
- [ ] 一次性/每周委托完成后，档案室能看到；点「再来一次」重挂为进行中。
- [ ] 已有结算的委托点「对结算有异议？」→ 聊天出现复核消息；设置里/记录里能看到复核结果。

## 4. 商店 / 技能 / 面板
- [ ] 商店买休整卷轴/热茶：金币扣减、持有数量 +1；金币不足时按钮禁用。
- [ ] 送礼：持有 -1，交情/亲密度上升。
- [ ] 技能树点亮一项：金币扣减，「已点亮」与统计更新。
- [ ] 面板：等级/评级/金币/六维雷达/称号/图鉴/周常 Boss 正常；月账单筛选、「导出 CSV」「导出 Markdown」能拉起系统分享。

## 5. 世界书 / 记忆书
- [ ] 世界书：新建、改名、挂给会长、新增条目（常驻/关键词/深度/顺序/概率）、复制、删除。
- [ ] 记忆书：永久记忆新增/编辑/停用/启用；酒馆对话后自动出现会话记忆；删除会话时提示「聊天记录和对话记忆一起消失」。
- [ ] 杀进程重开：世界书挂载与记忆仍在。

## 6. 角色卡导入 / 翻译 / AI 锻造
- [ ] 「导入角色卡」选一个 `.json` 或 `.png`（V1–V3）；卡内 `character_book` 的世界书条目应一并入册。
- [ ] 导入英文卡时弹出「要翻译吗？」；选翻译 → 进度/取消可用；完成后名字与提示词为中文。
- [ ] 「AI 生成」只填部分字段能补全；「创建这位会长」成功。

## 7. 跨天 / 签到 / 逾期
- [ ] 把手机日期往后调 1 天（或隔天再打开）：启动应补算，昨日未完成的日常委托变「逾期」。
- [ ] 持有休整卷轴时：断签被保全（卷轴 -1，连击不降），任务仍变逾期。
- [ ] 签到/连击/周常进度在面板与结算里更新。

## 8. 生图
- [ ] 聊天消息下「给这一幕配图」→ 出图并挂在该消息下；点图可全屏。
- [ ] 「停止」能中止；设置页测试生图能出图。

## 9. 稳定性
- [ ] 杀进程重开：会长、消息、委托、结算、商店库存、技能、世界书、记忆都在。
- [ ] 200+ 条记录时记录页能「加载更早」。
- [ ] 弱网/接口报错时：界面给出可读错误，不白屏、不崩。

## 已知限制
- 角色卡导入/翻译依赖系统文件选择器；模拟器上可能被动画/输入法卡住，真机一般正常。
- DeepSeek / OpenCode 真实渠道需要你自己的 Key；没有 Key 只验证自定义 API。
- 后台定时不是服务器 cron：App 完全关闭时不会准点巡检，下次打开/回前台补算。
- `torso_clothes_tshirt`、`legs_pants` 这两个素材正面行在 catalog 里为空（Web 同素材），默认已改用 Longsleeve 2 / Long Pants；设计器里仍可选择它们。
