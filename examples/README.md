# 世界书 / 角色卡 · 上手指南

> 面向「二周目协会」。文件都是酒馆（SillyTavern）生态的通用格式，本应用能直接吃。
> 配套示例：`gu-xia-lorebook.json`（示例世界书，可直接导入）。
>
> 角色卡示例因版权原因**未随仓库分发**，请自备 `.png` / `.json` 卡（见第五节"去哪找资源"）。

---

## 一、两种文件，分别怎么进协会

| 你手上的文件 | 是什么 | 入口 | 操作 |
|---|---|---|---|
| **角色卡** `.png` / `.json` | 一个完整角色（名字/性格/开场白，可能自带世界书） | `/masters` | 「导入角色卡」选文件 |
| **世界书** `.json` | 一堆关键词触发的设定（不含角色） | `/worldbook` | 「追加导入世界书」粘 JSON |

一句话：**角色卡 = 人；世界书 = 设定册。** 卡里若自带设定册（`character_book`），导入时会自动变成一本「<角色名>的世界书」并挂给它。

## 二、三分钟上手（推荐顺序）

### 第 1 步：导入一张角色卡（自备）
1. 打开 `/masters`（设置 → 协会 → 更换会长）。
2. 拉到底部「**导入角色卡**」→ 「选择角色卡文件」。
3. 选一张你自己的角色卡（`.png` / `.json`）。
4. 若卡里含外语，会弹窗询问是否翻译成中文。
5. 导入后回到上方列表，点「请 XX 执掌协会」。

### 第 2 步：导入一本世界书并挂给会长
1. 打开 `/worldbook`。
2. 在「**新建世界书**」里起个名（如「古巷镇」）→ 点「新建」。
3. 选中这本新书 → 拉到「**追加导入世界书**」→ 把 `examples/gu-xia-lorebook.json` 的内容整个粘进去 → 「追加」。
4. 点「**挂给会长**」→ 勾选你要的角色（可多选）。
5. 去聊天里说一句提到「**客栈**」或「**武当**」的话，世界书就会被注入。

### 第 3 步（可选）：从网上下载真实资源
见第五节「去哪找资源」。

## 三、世界书条目的五个开关

| 字段 | 意思 | 例子 |
|---|---|---|
| **触发关键词** | 命中了才注入（不区分大小写） | `客栈`、`钟楼` |
| **常驻** | 每轮都注入，不看关键词 | 「协会在旧钟楼」这类底层设定 |
| **需两把钥匙**（selective） | 关键词 + 次级关键词都命中才注入 | 关键词「武当」+ 次级「旧事」，防止过早剧透 |
| **位置** | 正文前 / 正文后 / 按深度 | 场景设定放正文前；旁白式提示放"按深度" |
| **顺序** | 数字越小越靠前 | 调优先级 |

> 参考酒馆的逻辑：位置「正文前/后」对应它的 *Before/After Char Defs*；「按深度」对应 *@ D*（插到对话历史里）。

---

## 四、多角色共用一个世界书（重点）

- 一本世界书可以**挂给多位会长**：新建后进「挂给会长」，勾多个即可。
- 一位会长也可以**挂多本**，全部叠加生效。
- 例：把「古巷镇」挂给薇拉和加洛，两人都知道这个镇；莱恩没挂就不知道。
- 没有"全局世界书"——世界书只随角色卡/会长走，想共用就挂给多个会长。

## 六、常见问题

**Q：导入卡后没看到世界书？**
去 `/worldbook` 看是否多了一本「X的世界书」。没有 = 这张卡不自带世界书（很常见）。

**Q：世界书改了会影响已有对话吗？**
只影响**之后的回合**，历史不动。

**Q：删掉会长，它的世界书会怎样？**
只有它一个在用 → 连书册一起删；**还挂着别人 → 书保留**，只拆掉它的挂载。

**Q：大世界书（上千条）会不会爆提示词？**
不会。只有命中关键词的条目才会被注入，且有 token 预算截断（超预算的条目自动丢弃）。

**Q：CHARX（`.charx` zip）能导入吗？**
暂不支持。`.png` / `.json` 可以。

**Q：导入失败报"不是合法 JSON"？**
多半是复制时带了多余字符，或下到的是 HTML 页面。重新打开原始链接、全选复制 JSON 全文再试。
